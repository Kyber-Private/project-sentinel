WINDOWS START
1. Extract this ZIP (do not run from inside the ZIP).
2. Install Ollama from https://ollama.com/download/windows if needed.
3. Make sure ports 3000 and 8000 are available (close old Sentinel servers).
4. Double-click Start Sentinel Local AI.bat in the project-sentinel folder.
5. Open http://localhost:3000 and start a NEW Nova Industries sample analysis.
6. Run VERIFY_REAL_OLLAMA.bat while the local backend is running.
   Only publish the live-AI claims after it reports ALL REAL OLLAMA CHECKS PASSED.
