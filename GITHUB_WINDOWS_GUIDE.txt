PROJECT SENTINEL — HOW TO PUBLISH THE SOURCE ON GITHUB (WINDOWS)

This folder is safe to use for a new GitHub repository: no API key, .env, database, or installed dependencies are included.

RECOMMENDED: GitHub Desktop (https://desktop.github.com/)
1. Extract this ZIP to a regular Windows folder.
2. Install GitHub Desktop and sign in to your GitHub account.
3. In GitHub Desktop, choose File > Add Local Repository.
4. Choose the extracted project-sentinel folder.
5. If told it is not a Git repository, click Create a Repository here.
6. Name it project-sentinel and select Create Repository.
7. Enter a commit summary like Initial hackathon submission; commit files.
8. Choose Publish repository. Select public if the hackathon requires a publicly accessible code link; otherwise choose private.
9. Copy the new GitHub repository URL for the Veritas AI hackathon submission.

IMPORTANT
- Do NOT upload the .env file from your working installation.
- Do NOT upload the backend/data folder or a ZIP of your running local installation.
- The source code itself does not include a valid OpenRouter API key. Judges will need their own key to run AI agents.
- Do NOT treat this as production-ready; see README.md.
